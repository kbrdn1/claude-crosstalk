# [0.1.0] - 2026-09-19

First release. crosstalk is a Claude Mod: a Claude Code plugin made of
function hooks, an early-access API behind
`CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`. Written and tested against Claude Code
2.1.277.

### Added

- **`/crosstalk`**, a pane that shows this session's conversations with the
  other Claude Code sessions on the machine and lets you answer them.
  Incoming peer messages (`session.receive`, origins `peer` and
  `peer-send-message`) and this session's `SendMessage` calls (`tool.call`)
  are recorded as they pass, unchanged. A local peer is named by its
  envelope's `from-name`, its `from` being a socket address.
- **Inbox**: one row a conversation, and one for each idle local session
  `ListAgents` reports (refreshed every 15 s while the pane is open), most
  recent first, with its status, its name whole, its unread count, its time
  and its last message.
- **Conversation**: messages grouped by side, pause and day, with Markdown
  bodies; your side on the right from 56 columns, both sides stacked left
  below, a bubble never past 72 columns. The thread is anchored on its
  newest message and scrolls (the wheel, the page keys, `↑ earlier` /
  `↓ newer`) while the header and the reply field stay. `✉ N` counts what
  arrived elsewhere, and each conversation keeps its own draft.
- **Reply field**: sends through `SendMessage`, to the peer's name while
  `ListAgents` lists it, else to the socket it last wrote from. A send no
  session answered is not drawn as sent; the reason shows in the pane.
- **Vim keys**, drawn as the pane's legend: insert and normal modes in a
  conversation (`esc` to normal mode, `i` to reply), `j k l g q` in the inbox,
  `j k d u g i h q` in normal mode. Arrows, `⏎`, the wheel and the page keys
  work as well.
- **History**: kept per session in the plugin's store across a reload, a
  restart and a `--resume` (the 50 most recent sessions), and rebuilt on a
  session's first start from its journal, messages from before the install
  included.
- **Renames**: a peer renamed at the same socket keeps its conversation.
- **Unread** count in the status line while the pane is closed.
- **Install**: the repo is its own plugin marketplace. `make install` adds it,
  installs `crosstalk` and merges the mods flag into the `env` of
  `~/.claude/settings.json`; `make update` and `make uninstall` follow, and
  `make dev` loads a checkout without installing anything.

### Known limits

- The function hooks API is early access and may change between Claude Code
  releases: after an update, `make types` then `make ci`.
- The history rebuilt from a session's journal reads Claude Code's own,
  undocumented format: a change there empties that history, nothing else.
  Replies typed in a pane before the history was kept are in no journal.
- Hotkeys are one lowercase letter or digit: shift is ignored (no `G` apart
  from `g`), and there is no `ctrl` or count.
- A key typed within about 400 ms of `esc` or of a switch between the inbox
  and a conversation goes to the prompt, while the pane takes the keys back.
