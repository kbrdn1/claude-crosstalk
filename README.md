# crosstalk

A [Claude Mod](https://github.com/anthropics/claude-code/tree/main/mods) to
chat with your other Claude Code sessions: `/crosstalk` opens a pane with this
session's conversations with its peers, and a field to answer them yourself.

> ⚠️ **Early WIP.** Mods run on Claude Code's function hooks, behind
> `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`, and may change between releases.

## Develop

```bash
make help
```
